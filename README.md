# 🗺️ Seoul Tour Guide - Frontend Project

A responsive, multi-page web application designed as a travel guide for **Seoul, South Korea**, showcasing semantic HTML5 structuring and user navigation.

---

## 🚀 Project Overview
This project demonstrates my transition from backend database engineering into user-facing web development.

### Key Pages:
*   **Home (`index.html`):** Introduction to South Korea's capital and history.
*   **Culture (`seoul culture.html`):** Explores heritage, arts, and traditions.
*   **Food (`seoul food.html`):** Highlights national cuisine and popular dishes.
*   **Registration (`seoul contact.html`):** A fully structured user registration form.

---

## 🛠️ Tech Stack & Concepts
*   **HTML5 Semantics:** Proper use of structural tags for clean layouts.
*   **Multi-Page Navigation:** Functional menus using unordered lists and relative paths.
*   **Form Validation:** Standardized text inputs, email fields, and text areas.
